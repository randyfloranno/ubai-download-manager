# ATTRIBUTION — UDM (Ubai Download Manager)

**EN** — Every non-code asset in this repository must be listed here, in the same commit that adds it. Code dependencies are governed by `plan/adr/0001-dependencies.md` and `deny.toml`; their licence texts are collected into the release bundle by `cargo xtask licences`.

**ID** — Setiap aset non-kode di repositori ini wajib dicantumkan di sini, di commit yang sama dengan penambahannya. Dependensi kode diatur oleh `plan/adr/0001-dependencies.md` dan `deny.toml`; teks lisensinya dikumpulkan ke paket rilis oleh `cargo xtask licences`.

## 1. Allowed / Diizinkan

| EN | ID |
|---|---|
| Assets created from scratch by UDM contributors (icons, illustrations, sounds), with the author named below. | Aset yang dibuat dari nol oleh kontributor UDM (ikon, ilustrasi, suara), dengan nama pembuat dicantumkan di bawah. |
| Icon sets and fonts under permissive licences: MIT, Apache-2.0, BSD, ISC, SIL OFL 1.1 (fonts only), CC0, CC BY 4.0 (with credit). | Set ikon dan font berlisensi permisif: MIT, Apache-2.0, BSD, ISC, SIL OFL 1.1 (khusus font), CC0, CC BY 4.0 (dengan kredit). |
| File-type and MIME tables built from public standards (IANA media types registry, RFCs) or permissively licensed data. | Tabel jenis berkas dan MIME yang disusun dari standar publik (registri media type IANA, RFC) atau data berlisensi permisif. |
| Test fixtures generated by our own code (e.g. deterministic pseudo-random `.bin` files with known SHA-256) — record the generator, not each file. | Fixture tes yang dihasilkan kode kita sendiri (mis. berkas `.bin` pseudo-acak deterministik dengan SHA-256 yang diketahui) — catat generatornya, bukan tiap berkas. |
| Browser names and logos only where the browser vendor's brand guidelines allow (e.g. "Available for Firefox" badges), never altered. | Nama dan logo browser hanya bila pedoman merek vendornya mengizinkan (mis. lencana "Tersedia untuk Firefox"), tanpa diubah. |
| Screenshots of UDM itself for docs, taken with sample data only (no real URLs, cookies or user names). | Tangkapan layar UDM sendiri untuk dokumentasi, diambil hanya dengan data contoh (tanpa URL nyata, cookie, atau nama pengguna). |

## 2. Forbidden / Dilarang

| EN | ID |
|---|---|
| Any Internet Download Manager (IDM) asset: logo, icons, toolbar images, tray icon, "download panel" artwork, sounds, dialogs, help text, installer text, extension files, language files, or anything traced from or confusingly similar to them. | Aset Internet Download Manager (IDM) apa pun: logo, ikon, gambar toolbar, ikon tray, tampilan "panel unduh", suara, dialog, teks bantuan, teks installer, berkas ekstensi, berkas bahasa, atau apa pun yang dijiplak darinya atau mirip sampai membingungkan. |
| Screenshots of IDM in the repo, docs or store listings. | Tangkapan layar IDM di repo, dokumentasi, atau halaman toko ekstensi. |
| Assets, code, icons or translations from GPL/LGPL/AGPL projects in this domain, e.g. aria2, GNU Wget, uGet, Xtreme Download Manager, JDownloader, Persepolis, KGet, FlashGot. | Aset, kode, ikon, atau terjemahan dari proyek GPL/LGPL/AGPL di domain ini, mis. aria2, GNU Wget, uGet, Xtreme Download Manager, JDownloader, Persepolis, KGet, FlashGot. |
| Icons or fonts with "free for personal use", "non-commercial", unclear or missing licences. | Ikon atau font berlabel "free for personal use", "non-commercial", lisensi tidak jelas, atau tanpa lisensi. |
| Logos of websites, video platforms or file hosts (YouTube, Google Drive, Mega, etc.) in the UI, sample data or marketing. | Logo situs web, platform video, atau penyedia berkas (YouTube, Google Drive, Mega, dll.) di UI, data contoh, atau materi promosi. |
| Copyrighted media (films, music, software installers, e-books) as test fixtures or sample downloads. Sample data points only at `udm-testsrv`. | Media berhak cipta (film, musik, installer software, e-book) sebagai fixture tes atau contoh unduhan. Data contoh hanya mengarah ke `udm-testsrv`. |
| Anything related to DRM keys, decryption modules, or paywall/captcha bypass lists. | Apa pun yang terkait kunci DRM, modul dekripsi, atau daftar bypass paywall/captcha. |
